# STM32 双轮编码器测速与 PI 速度闭环控制

## 项目简介

本项目基于 STM32F103，实现智能小车左右轮的编码器测速和 PI 速度闭环控制。

STM32每隔100ms读取一次左右轮编码器脉冲数，将实际速度与目标速度进行比较，再通过增量式PI算法调整电机PWM，使左右轮速度尽量接近设定值。

该项目是在PWM开环电机驱动的基础上，进一步加入编码器反馈和闭环控制。

## 已完成功能

- 使用TIM2读取左轮编码器
- 使用TIM3读取右轮编码器
- 每100ms采集一次左右轮编码器脉冲数
- 使用TIM4输出左右电机PWM
- 实现左右轮独立的增量式PI控制
- 支持前进、后退、转弯、原地旋转和停止
- 支持USART1串口控制
- 串口输出目标速度、实际速度和PWM
- 上电后默认停止
- 通信超过1秒无指令时自动停车
