# STM32 PID 电机闭环控制——9 月 1 日联调记录

## 今日目标

在保留原有编码器测速、增量式 PI 和 SysTick 调度结构的前提下，为小车增加可由串口助手直接发送的数据控制接口。

## 初始问题

开始联调时，烧录 `6_PID` 工程后小车对串口数值输入没有可观察的动作，无法确认命令是否到达 STM32，也不能用两路数据单独控制左右电机。

## 今日完成的代码改动

改动没有调整 `USER/main.c` 的主流程，主循环仍持续调用 `Control_Task()`。主要实现位于 `QST_HARDWARE/control_systems/control_systems.c`：

- 增加 `左值,右值` 的文本命令解析，例如 `60,60`；串口助手无需附加换行。
- 使用 20 ms 空闲时间判断一条文本命令已接收完成，避免依赖特定串口助手的“自动换行”选项。
- 增加手动 PWM 控制支路：输入范围为 `-100` 到 `100`，映射为 `-4000` 到 `4000` 的 PWM 输出。
- 保留 PID 控制支路；手动调试和 PID 闭环分别运行，不改变原有编码器测速接口。
- 增加 5 秒命令超时停车保护，避免通信中断后电机持续输出。
- 串口收到有效命令后返回 `ACK 左值,右值`，无效命令返回错误并停车。
- 完善 USART1 接收 FIFO、发送缓存和 `printf` 串口重定向，便于观察控制状态。

## 串口数据格式

串口参数：`115200 / 8N1`。

| 输入数据 | 功能 |
| --- | --- |
| `60,60` | 双轮正转，约 60% PWM |
| `-60,-60` | 双轮反转，约 60% PWM |
| `0,60` | 单侧转动，用于转向与电机检查 |
| `60,0` | 另一侧转动，用于转向与电机检查 |
| `0,0` | 立即停止 |

## 联调结果

串口助手已收到 `ACK 100,100` 回执，说明数值命令已成功到达 STM32 并进入电机控制分支；小车可对单侧 PWM 命令产生动作响应。相较于最初串口输入后无动作、无法判断控制状态的情况，现已完成“串口数据接收 → 命令解析 → PWM 输出 → 串口回执”的可观测控制链路。

后续将继续在实车上校准两轮启动 PWM、检查右侧电机机械阻力与供电稳定性，并把已验证的手动控制参数作为 PID 闭环调试的初始参数。
