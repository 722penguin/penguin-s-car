# STM32编码器测速实验

## 实验目标

使用STM32F103的定时器编码器模式，读取无人车左右轮编码器在固定时间内产生的脉冲数，为后续计算轮速和实现闭环控制做准备。

## 硬件与定时器分工

- TIM2：读取一侧车轮的编码器
- TIM3：读取另一侧车轮的编码器
- SysTick：每1毫秒产生一次中断
- 串口：波特率为115200，用于输出测试结果

## 程序流程

1. 初始化STM32系统时钟和串口。
2. 初始化TIM2和TIM3的编码器模式。
3. 配置SysTick每1毫秒进入一次中断。
4. 每经过100毫秒设置一次采样标志。
5. 主循环检测标志并读取左右轮编码器计数。
6. 通过串口输出左右轮在100毫秒内产生的脉冲数。

## 实验现象

小车静止时，左右轮编码器计数接近0。用手转动左轮或右轮时，对应的计数发生变化。计数为正数或负数代表车轮旋转方向不同。

## 当前进度

目前已经实现左右轮编码器脉冲计数。当前输出值还不是米每秒，下一步需要测量车轮周长和车轮旋转一圈对应的编码器脉冲数，再将计数换算成实际速度。

## 今日收获

了解了定时器编码器模式、SysTick定时中断和主循环之间的配合方式，也解决了SysTick_Handler重复定义的问题。
